What it does

Fourteen tools that turn a sentence into something your speakers actually do.

Ask for “a rainy-Sunday playlist from my library” or “skip this and turn it down.” The server translates it into precise operations on the Music app — and everything it touches propagates to your other devices through iCloud Music Library.

01

Speaks plain English

No commands to memorize. Describe the vibe, the mood, the constraint — Claude picks the tracks and does the work.

02

Never grabs the wrong song

Every operation runs on Music’s persistent track IDs, not fuzzy name matching. Batch actions report exactly what landed and what didn’t.

03

Follows you everywhere

It drives Music on your Mac. New playlists, edits, ratings and favorites sync to your iPhone and iPad in seconds.

The surface

Everything Claude can reach.

Mac in, iPhone out

Build it on the desktop. Play it on the train.

The server controls the Music app where it runs — your Mac. With iCloud Music Library on, every change it makes rides that sync straight to your phone. There’s no separate app to install on iOS and nothing to configure. Make a playlist here; it’s in your pocket before you’ve closed the laptop.

Built safe

Injection isn’t patched out. It’s designed out.

Every value you give the server — a search term, a playlist name — reaches AppleScript as a positional argument behind a -- terminator, never concatenated into script source. A track literally named "; do shell script … is just a string. No eval, no shell, no network surface.

# one gateway. values are data, never code. cmd = ["osascript", "-e", script, "--", *args] # ↑ terminator: everything # after this is argv data subprocess.run(cmd, timeout=120)

Install.

You’ll need macOS with the Music app, an Apple Music subscription, uv, and Sync Library switched on.

Claude Code
$ claude mcp add applemusic -- \
    uvx --from \
    git+https://github.com/NodeSaint/mcp-applemusic \
    mcp-applemusic

Where it’s going

Roadmap.

Shipped · live-tested

Phase 1 — Your library

All 14 tools over AppleScript: playback, search, ratings, full playlist CRUD. Works today, no developer account, 38 tests green plus an end-to-end run against a real 2,800-track library.

Designed · next

Phase 2 — The whole catalog

The Apple Music Web API layer: search all of Apple Music, add songs you don’t own yet, native cloud playlists. Spec’s written; it needs an Apple Developer key to switch on.
